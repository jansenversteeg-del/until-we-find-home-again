# Background Music Guide

To make the story experience lovely and cinematic, you can add any MP3 background track you like!

## How to Set Your Music

1. **Get an MP3 file**: Download a lovely, ambient, or piano instrumental track (such as from Mixkit, Bensound, or Chosic).
2. **Place it in this directory**: Save the file inside `assets/music/` and name it `music.mp3` (to match the existing code).
3. **Alternatively, use a custom filename**:
   If your file is named something else (e.g. `lovely-piano.mp3`), open `index.html` and update the audio tag source attribute:
   ```html
   <audio id="cinematicAudio" loop src="assets/music/lovely-piano.mp3"></audio>
   ```

## Recommended Free Music Libraries
- **[Mixkit Free Piano Music](https://mixkit.co/free-stock-music/piano/)** (Snappy, free MP3 direct downloads)
- **[Chosic Free Background Music](https://www.chosic.com/free-music/all/)** (Lovely ambient piano selections)
- **[Bensound Piano Stock Music](https://www.bensound.com/royalty-free-music/piano)** (High-quality stock instrumentals)
